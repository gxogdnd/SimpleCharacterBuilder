# The Learning Path

Welcome! This is a guided tour of how real open-source contribution works,
using SimpleCharacterBuilder as a friendly practice ground.

You don't have to read everything up front. Each guide is meant to be opened
**when you first reach that step**. If you only read one thing first, make it
[CONTRIBUTING.md](../../CONTRIBUTING.md) — it's the short version of this whole
path.

## The guides

1. [Setting up your tools](01-setup.md) — GitHub account, git, Python, and the project
2. [Understanding the project](02-understanding-the-project.md) — how the code fits together
3. [Claiming your first issue](03-finding-an-issue.md) — finding work and saying you'll do it
4. [Branching and making a change](04-branching-and-changes.md) — the safe way to edit code
5. [Writing tests with pytest](05-writing-tests.md) — proving your change works
6. [Linting, formatting, and CI](06-linting-and-ci.md) — ruff and the automated checks
7. [Opening a pull request](07-opening-a-pr.md) — sharing your change for review
8. [Working through review](08-code-review.md) — responding to feedback
9. [Updating documentation](09-updating-docs.md) — keeping the docs honest
10. [Tackling an enhancement](10-tackling-an-enhancement.md) — a bigger, multi-file change

## How to use this

- Work on **one issue at a time**, start to finish. Finishing a small thing
  teaches more than half-finishing a big thing.
- Mistakes are expected and welcome. Nothing you do on a branch or a PR can
  break the project for anyone else.
- Stuck? Open a [Discussion](https://github.com/gxogdnd/SimpleCharacterBuilder/discussions)
  or ask on your issue. "I don't understand this yet" is always a fine thing
  to say.
